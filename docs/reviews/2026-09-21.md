## Confirmed findings and fixes

1. **P1 — Save acknowledgements could erase newer graph edits. Confidence: 100.** Add node and Delete connection remained available during save/publish. The saved response unconditionally replaced the rule and marked the document clean. The reducer now acknowledges the submitted snapshot, preserves later edits and advances the server revision/baseline. Graph mutation commands also consistently respect pending work. Build, render and diagnostic responses carry their originating buffer or graph identity. [Original mutation controls](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/frontend/src/features/editor/GraphCanvas.tsx#L136-L147), [original acknowledgement](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/frontend/src/features/editor/documentState.ts#L62-L69).

2. **P1 — A source save could replace another source's unsaved document. Confidence: 100.** Save A, select and edit B, then receive A's response: the controller called `choose(saved)` without checking selection identity. Source tests could similarly display A's result under B or a different version. A source document now owns its selection and request identities, raw JSON buffers and saved baseline. Successful saves update the source list independently; only matching acknowledgements update the open document. Test completion requires the current request. [Original source command completion](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/frontend/src/features/sources/useSourceEditor.ts#L111-L143), [selection during requests](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/frontend/src/components/SourcesPage.tsx#L74-L81).

3. **P2 — Stale execution responses could restore old results, trace or errors. Confidence: 100.** Changing test inputs or the graph cleared the UI but did not invalidate the pending preview. Closing the panel also left callbacks able to write into the parent editor. Published execution had the same request-lifecycle duplication. Both use `useExecutionRequest`, keyed by execution target and input buffer, with cancellation and completion guards. [Original preview lifecycle](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/frontend/src/components/TestPanel.tsx#L95-L121).

4. **P2 — Decimal remainder failures escaped the expression error contract. Confidence: 100.** `1e40 % 3` is a valid bounded expression, but its integer quotient exceeds DECIMAL128 precision. `BigDecimal.remainder` threw an unhandled `ArithmeticException`: HTTP 500, no node location, and no `IFERROR` fallback. Decimal arithmetic failures now become `ArcException`, preserving the existing precision policy and normal error navigation. [Original remainder operation](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/backend/src/main/java/dev/arc/engine/Expressions.java#L130-L143).

5. **P2 — Minimum integer rounding precision bypassed the bounds check. Confidence: 100.** `ROUND(1, -2147483648)` passed `Math.abs(scale) > 12` because the absolute value overflowed, then failed inside `setScale`. All three rounding functions now compare directly against the lower and upper bounds and return the normal validation error. [Original precision check](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/backend/src/main/java/dev/arc/engine/Functions.java#L62-L78).

6. **P2 — JSON-escaped string constants changed value during execution. Confidence: 100.** The frontend encodes literals with `JSON.stringify`, but the expression parser discarded the slash for `\b`, `\f` and `\uXXXX`. These escapes now decode correctly, including Unicode surrogate pairs and single-quoted expressions. Malformed Unicode escapes return a syntax error. This is an intentional correction to expression semantics, rather than a behavior-preserving extraction. [Original string decoder](https://github.com/SoooEZ/arc/blob/871241837538c5cac7b1d46c89a69895864c3530/backend/src/main/java/dev/arc/engine/Expressions.java#L292-L313).

## Maintainability changes

These are structural improvements, separate from the defects above:

| Boundary | Change and reason |
| --- | --- |
| Studio compiler | `ArcScript` retains its public facade and node-fragment merge policy. Scanner, parser and canonical renderer have separate ownership, so text formatting changes do not require navigating graph replacement and parsing logic. Typed assignments replace positional string arrays. |
| Validation | `Validator` names its input-dependency, connection, reachability and node-validation phases. `DefinitionShape`, `InputValidation` and `NodeValidation` separate draft shape, parameter types and node semantics. Executable checks and syntax-only diagnostics share expression enumeration, eliminating duplicate Switch/Transform coverage. |
| Rule document | Snapshot-aware reducer transitions enforce async correctness independently of UI controls. Command orchestration stays in `useRuleDocument`. |
| Execution UI | A narrow execution-request hook owns cancellation and completion. JSON parsing, sample inputs and cURL text live in a pure domain module; the API page no longer imports a UI component for these helpers. Trace presentation and problem navigation remain in TestPanel. |
| Node code editor | `useNodeExpressionDraft` owns one local buffer, render/check/apply requests and errors. The dialog owns presentation and Monaco integration. A node key defines the editing session. |
| Source editor | Pure document transitions, raw-buffer serialization and sample generation are separate from IO. Provider configuration and test presentation have their own components. Source identity, saved baseline and request state no longer depend on a collection of unrelated setters. |
| Reuse snippets | Reference binding and DSL generation live in a pure studio function, leaving CodeStudio responsible for selection, fetching the version and insertion. |
| Architecture checks | Pure-module checks now cover source document/buffer logic and snippet generation as well as rule state, domain functions and HTTP clients. |

No dependencies, database migrations, public graph fields, node-plugin hierarchy or generic repository framework were introduced. Existing Repository, source Strategy/registry, Excel Adapter, request-scoped resolver Decorator and reducer boundaries remain in place. The extension map is documented in [Maintaining ARC](../maintaining.md).

## Remaining limits

A whole-project review is not proof that every input and schedule is correct. This pass focused on confirmed defects and responsibilities that already caused duplicated policy or unsafe state ownership. The cohesive expression parser, branch-sensitive graph planner and obstacle-routing algorithm remain explicit algorithms; their size alone did not justify a new abstraction. The stylesheet and static page presentation were inspected without a cosmetic rewrite. Authentication remains intentionally deferred by the product scope.
