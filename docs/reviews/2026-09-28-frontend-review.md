# Frontend review: findings and fixes (2026-09-28)

> 中文说明：这是 2026-09-28 针对前端的专项 review（可读性、无 bug、可复用、可扩展、文件不过大、位置正确）的问题清单。评审报告了 15 条，另有 18 条因数量上限被截掉但同样确认；8 条候选被评审自己排除，不在此记录。每条写明问题、修复方式和回归测试。全部 33 条已在本提交中修复。

## Scope and status

- Reviewed: the `second-review-fixes` branch after commit `0b7c08e`, frontend only (`frontend/src`, `frontend/tests`, the frontend rows of `scripts/check_architecture.py`).
- Method: a review agent read every frontend module against the project conventions, then re-verified each candidate against the code and, where a browser was needed, against a disposable stack. 15 findings were reported through the review tool; 18 more were confirmed but cut by the report cap; 8 candidates were refuted.
- Status: all 33 confirmed findings are fixed in this commit. Each fix carries a regression test that failed before the change; browser tests ran against a disposable Compose project (`arc-fix`, ports 3190/8190).
